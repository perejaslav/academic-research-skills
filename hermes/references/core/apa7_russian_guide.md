# APA 7.0 — Русский гайд (краткий)

## Формат цитирования в тексте

| Ситуация | Формат | Пример |
|----------|--------|--------|
| Один автор | (Фамилия, год) | (Иванов, 2024) |
| Два автора | (Фамилия1 и Фамилия2, год) | (Иванов и Петров, 2024) |
| Три+ автора | (Фамилия1 и др., год) | (Иванов и др., 2024) |
| Организация | (Название, год) | (Яндекс, 2025) |
| Прямая цитата | (Фамилия, год, с. N) | (Иванов, 2024, с. 15) |
| Несколько источников | (Автор1, год; Автор2, год) | (Иванов, 2024; Петров, 2023) |

## Формат списка литературы (References)

### Книга
```
Фамилия, И. О. (Год). *Название книги* (изд., если не первое). Издательство.
```
Пример: Иванов, И. И. (2024). *Цифровой маркетинг в России*. Эксмо.

### Статья в журнале
```
Фамилия, И. О. (Год). Название статьи. *Название Журнала, том*(номер), страницы. URL
```
Пример: Петров, П. А. (2024). Нейросети в контекстной рекламе. *Маркетинг и реклама, 15*(2), 34-45. https://cyberleninka.ru/...

### Веб-страница
```
Автор/Организация. (Год). *Название страницы*. Название сайта. URL
```
Пример: Яндекс. (2025). *Нейрообъявления β*. Яндекс Директ. https://yandex.ru/support/direct/...

### Источник на английском
```
Author, A. A. (Year). *Title of work* (edition). Publisher. https://doi.org/xxxxx
```

## Правила для русскоязычных статей
- Русские источники — на кириллице, идут в начале списка (по алфавиту)
- Английские — латиницей, после русских (по алфавиту)
- Все ссылки в тексте — на русском языке статьи
- Если у источника есть DOI — указать в конце
- URL только для открытых источников (не для закрытых БД)
