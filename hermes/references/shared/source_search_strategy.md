# Стратегия поиска источников (Hermes ARS)

**Статус**: v1.0
**Используется**: bibliography_agent, literature_strategist_agent, source_verification_agent
**Заменяет**: semantic_scholar_api_protocol.md, openalex_api_protocol.md, crossref_api_protocol.md

---

## Принцип

Приоритет — русскоязычные академические источники. Если их недостаточно или они
недоступны — расширяем до любых авторитетных. Каждый источник в библиографии
должен содержать пометку типа: `академический`, `отчёт`, `аналитика`, `СМИ`.

---

## Каскад поиска (порядок приоритета)

### Уровень 1: Киберленинка (основной академический)

Крупнейшая русскоязычная библиотека открытого доступа. Нет API — парсинг.

```
Поиск: web_search("site:cyberleninka.ru KEYWORD1 KEYWORD2")
Альтернатива: web_search("site:cyberleninka.ru \"exact phrase\"")
Чтение: web_extract(urls=["https://cyberleninka.ru/article/n/SLUG"])
```

Извлекает: заголовок, авторов, журнал, аннотацию, ключевые слова.
Формат URL: `https://cyberleninka.ru/article/n/transliterated-slug`

**Фильтрация результатов:**
- Проверять, что статья относится к целевой теме (аннотация, ключевые слова)
- Отсеивать дубликаты (одна статья может быть в нескольких журналах)
- Приоритет: статьи из ВАК-журналов, РИНЦ-индексированных

### Уровень 2: eLibrary / РИНЦ

Главная наукометрическая база РФ.

```
Поиск: web_search("site:elibrary.ru KEYWORDS")
Чтение: web_extract(urls=["https://elibrary.ru/item.asp?id=XXXXX"])
```

Извлекает: метаданные, РИНЦ-индекс, цитирования, журнал.
**Ограничение**: полные тексты часто за paywall, но метаданные и аннотации доступны.

### Уровень 3: Google Scholar (русский сегмент)

```
Поиск: web_search("KEYWORDS научная статья")
Фильтр: отдавать приоритет результатам с .ru доменов
```

Широкий охват, но высокий шум. Использовать для обнаружения статей,
затем верифицировать через Киберленинку или eLibrary.

### Уровень 4: Авторитетные неакадемические

Когда академических источников недостаточно:

| Тип | Примеры доменов | Поисковый запрос |
|-----|----------------|------------------|
| Гос. отчёты | gov.ru, minobrnauki.gov.ru | `"KEYWORDS" отчёт аналитика site:gov.ru` |
| Отраслевые СМИ | vedomosti.ru, rbc.ru, kommersant.ru | `"KEYWORDS" site:vedomosti.ru` |
| Консалтинг | mckinsey.com/ru, deloitte.com/ru | `"KEYWORDS" аналитика отчёт` |
| Энциклопедии | bigenc.ru, encyclopaedia_britannica | `"KEYWORDS" определение обзор` |
| Отраслевые порталы | habr.com (для IT), cnews.ru | `"KEYWORDS" исследование` |

**Правила:**
- СМИ — только для фактов, событий, цитат экспертов. НЕ для научных утверждений.
- Отчёты консалтинга — для статистики, рынков, прогнозов.
- Wikipedia — только как отправная точка для навигации. НЕ как источник.

### Уровень 5: Semantic Scholar (англоязычный fallback)

```
API: curl -s "https://api.semanticscholar.org/graph/v1/paper/search?query=KEYWORDS&limit=5&fields=title,authors,year,abstract,citationCount"
Rate limit: 1 req/sec (без ключа)
```

Использовать только если:
- Тема международная и русских источников мало
- Нужна кросс-валидация русского источника
- Нужны цитирования (who cited this)

### Уровень 6: arXiv (препринты, ML/AI)

```
Через skill arxiv: python scripts/search_arxiv.py "KEYWORDS" --sort date --max 10
Или: curl "https://export.arxiv.org/api/query?search_query=all:KEYWORDS&max_results=5"
```

Только для: ML/AI, компьютерные науки, математика, физика.
Не подходит для: гуманитарных, социальных, экономических наук.

## Протокол верификации источников

### Трёхуровневая проверка

| Уровень | Метод | Порог |
|---------|-------|-------|
| Tier 0 | Проверка URL — статья доступна по ссылке | URL открывается |
| Tier 1 | Проверка метаданных — автор, журнал, год | Все поля заполнены |
| Tier 2 | Проверка содержания — аннотация соответствует теме | Ключевые слова совпадают |

### Типы источников (обязательная пометка)

```
[А] Академический — рецензируемый журнал, сборник конференции, монография
[О] Отчёт — государственный, корпоративный, исследовательский
[Ан] Аналитика — консалтинг, отраслевые исследования
[С] СМИ — новостные статьи, интервью, экспертные мнения
[P] Препринт — arXiv, SSRN, РИНЦ (до рецензирования)
```

## Формат записи источника (APA 7.0 + тип)

```markdown
1. Иванов И.И. (2024). Применение ИИ в маркетинге. *Вестник МГУ*, 45(2), 112-125. [А]
   URL: https://cyberleninka.ru/article/n/primenenie-ii-v-marketinge
   Аннотация: Обзор современных методов применения ИИ в цифровом маркетинге...
   Тип: Академический | Источник: Киберленинка | Проверен: ✓
```

## Pitfalls (подводные камни)

1. **Киберленинка может быть недоступна** — сайт иногда падает. Fallback на Google Scholar.
2. **eLibrary блокирует автоматические запросы** — rate limiter + CAPTCHA после 10-15 запросов. Использовать web_search вместо прямого парсинга.
3. **Дубликаты** — одна статья может быть на Киберленинке И в eLibrary. Дедуплицировать по DOI/названию.
4. **Качество русскоязычных источников** — не все журналы в РИНЦ рецензируются. Приоритет: ВАК-журналы > РИНЦ > остальные.
5. **Переводные статьи** — иногда на Киберленинке есть переводы иностранных статей. Указывать оригинал.
6. **Устаревшие источники** — по умолчанию: последнее 10 лет + семинальные работы. Для IT/AI — 5 лет.
